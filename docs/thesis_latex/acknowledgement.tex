คณะผู้จัดทำขอขอบพระคุณ ผศ.ดร.ไอศูรย์ กาญจนสุรัตน์ อาจารย์ที่ปรึกษาโครงงาน ที่ได้กรุณาให้คำแนะนำ คำปรึกษา และข้อเสนอแนะอันเป็นประโยชน์ ตลอดระยะเวลาการดำเนินโครงงานฉบับนี้ รวมทั้งสละเวลาในการตรวจแก้ไขและให้กำลังใจ จนทำให้โครงงานนี้สำเร็จลุล่วงไปได้ด้วยดี

ขอขอบพระคุณ ผศ.นพ.ชัยวัชร์ อภิวาทนสิริ อาจารย์ที่ปรึกษาร่วม สาขาวิชาพยาธิวิทยา คณะแพทยศาสตร์ มหาวิทยาลัยขอนแก่น ที่ได้กรุณาให้คำแนะนำด้านขั้นตอนการตรวจชิ้นเนื้อด้วยตาเปล่า (Gross Examination) ศัพท์เฉพาะทางพยาธิวิทยา และแบบฟอร์มรายงานตามโปรโตคอล CAP ซึ่งเป็นส่วนสำคัญยิ่งในการพัฒนาระบบให้สอดคล้องกับการใช้งานจริงทางการแพทย์

ขอขอบพระคุณคณาจารย์ในสาขาวิชาปัญญาประดิษฐ์ วิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น ทุกท่านที่ได้ถ่ายทอดความรู้ทางวิชาการ ซึ่งเป็นพื้นฐานสำคัญในการศึกษาค้นคว้าและจัดทำโครงงานนี้ ขอบคุณเพื่อนร่วมชั้นและผู้ที่เกี่ยวข้องทุกท่านที่ช่วยเหลือและแลกเปลี่ยนความคิดเห็น

ท้ายที่สุดนี้ คณะผู้จัดทำขอขอบพระคุณบิดา มารดา และครอบครัว ที่ให้การสนับสนุนและเป็นกำลังใจตลอดระยะเวลาของการศึกษา
