\section{ความเป็นมาและความสำคัญของโครงงาน}
การตรวจชิ้นเนื้อทางศัลยพยาธิวิทยาด้วยตาเปล่า (Gross Examination) ในโรคมะเร็งเต้านม เป็นขั้นตอนวิกฤตที่พยาธิแพทย์ต้องวัดขนาดสิ่งส่งตรวจ ประเมินรอยโรค ขอบตัดผ่าตัด (Surgical Margin) และต่อมน้ำเหลือง เพื่อบันทึกข้อมูลลงในแบบฟอร์มมาตรฐาน CAP (College of American Pathologists) \cite{cap_breast, ajcc2017} อย่างไรก็ตาม ผู้ตรวจต้องสวมถุงมือที่สัมผัสสารเคมีและฟอร์มาลินตลอดเวลา จึงไม่สามารถพิมพ์บันทึกข้อมูลลงคอมพิวเตอร์ได้โดยตรง กระบวนการดั้งเดิมที่ใช้วิธีอัดเสียงหรือจดโน้ตย่อแล้วนำมาพิมพ์ในภายหลัง ก่อให้เกิดความล่าช้าและเสี่ยงต่อความผิดพลาดในการถ่ายโอนข้อมูล (Transcription Error) \cite{zhou2018errors} ซึ่งการศึกษาของ Zhou และคณะ พบว่าเอกสารทางคลินิกที่บันทึกด้วยระบบรู้จำเสียงพูดทั่วไปมีอัตราความผิดพลาดสูงถึงร้อยละ 7.4 โดยเฉพาะข้อมูลตัวเลขและคำศัพท์เฉพาะทาง \cite{zhou2018errors} นอกจากนี้ ระบบรู้จำเสียงส่วนใหญ่ที่ใช้งานผ่านคลาวด์ยังสุ่มเสี่ยงต่อการละเมิดความเป็นส่วนตัวของผู้ป่วยตามกฎหมาย PDPA และมาตรฐาน HIPAA ขณะเดียวกัน สภาพแวดล้อมในห้องปฏิบัติการจริงยังมีเสียงรบกวนความถี่ต่ำจากพัดลมตู้ดูดควันฟอร์มาลิน (Fume Hoods) \cite{radford2023whisper} ซึ่งหากใช้ตัวกรองเสียงรบกวนแบบคงที่ตลอดเวลา จะไปตัดทอนเสียงพยัญชนะสั้นในศัพท์แพทย์ ส่งผลให้ความแม่นยำลดลง

 
การพัฒนาระบบรู้จำเสียงพูดและสกัดข้อมูลอัตโนมัติที่สามารถทำงานแบบออฟไลน์บนคอมพิวเตอร์ส่วนบุคคล จึงเป็นทางออกสำคัญในการรักษาความปลอดภัยของข้อมูลสุขภาพผู้ป่วย พร้อมทั้งช่วยขจัดอุปสรรคด้านสภาวะแวดล้อมทางกายภาพในห้องปฏิบัติการ ด้วยการประยุกต์ใช้กลไกคัดกรองเสียงรบกวนแบบปรับตัว (Blind SNR Gate) ร่วมกับการกำหนดข้อความนำบริบท (Prompt Conditioning) และการปรับแต่งค่าน้ำหนักแบบจำลอง Whisper ด้วยเทคนิคพารามิเตอร์จำนวนน้อย (LoRA) ซึ่งช่วยให้ระบบสามารถถอดความคำศัพท์ทางการแพทย์และมิติตัวเลขได้อย่างแม่นยำ ทนทานต่อเสียงรบกวนพัดลม และประมวลผลได้อย่างรวดเร็วบนหน่วยประมวลผลกลาง (CPU)

   
การแก้ปัญหาดังกล่าวจะช่วยเปลี่ยนผ่านกระบวนการบันทึกผลการตรวจชิ้นเนื้อจากการพิมพ์ด้วยมือไปสู่ระบบอัตโนมัติ ช่วยลดภาระงานเอกสารของพยาธิแพทย์ ลดระยะเวลาในการจัดทำรายงาน และลดอัตราความผิดพลาดวิกฤตในข้อมูลสำคัญทางคลินิก ตลอดจนได้ต้นแบบสถาปัตยกรรมระบบแอปพลิเคชันที่ประมวลผลข้อมูลภายในเครื่องโดยไม่พึ่งพาอินเทอร์เน็ต ซึ่งสอดคล้องกับมาตรฐานการคุ้มครองข้อมูลส่วนบุคคลทางการแพทย์อย่างเคร่งครัด
    


\section{วัตถุประสงค์ของโครงงาน}
\begin{enumerate}
    \item เพื่อพัฒนาระบบแปลงเสียงบรรยายผลการตรวจชิ้นเนื้อทางศัลยพยาธิวิทยาเป็นข้อความและสกัดข้อมูลลงแบบฟอร์มมาตรฐาน 15 ฟิลด์ ตามเกณฑ์ CAP แบบออฟไลน์บนเครื่องคอมพิวเตอร์ส่วนบุคคล
    \item เพื่อศึกษาและบูรณาการกลไกคัดกรองสัญญาณรบกวนจากตู้ดูดควันแบบปรับตัว เข้ากับการกำหนดข้อความนำบริบท (Prompt Conditioning) และการปรับแต่งค่าน้ำหนักแบบจำลองด้วยเทคนิค LoRA เพื่อยกระดับความแม่นยำในการถอดความคำศัพท์เฉพาะทางศัลยพยาธิวิทยาและตัวเลขมิติ
    \item เพื่อพัฒนาตัวสกัดข้อมูลทางคลินิกแบบกำหนดแน่นอนร่วมกับกลไกแจ้งเตือนความปลอดภัยทางคลินิกหลายสัญญาณ สำหรับแปลงข้อความถอดความลงในแบบฟอร์มตรวจชิ้นเนื้อมะเร็งเต้านมและสร้างเอกสารรายงานผลในรูปแบบ PDF โดยอัตโนมัติ
    \item เพื่อประเมินประสิทธิภาพของระบบเทียบกับแบบจำลองพื้นฐาน โดยพิจารณาอัตราความผิดพลาดระดับคำ (WER) เวลาในการประมวลผล และความถูกต้องของการสกัดข้อมูลลงฟิลด์
\end{enumerate}

\section{ขอบเขตของโครงงาน}

\subsection{ข้อมูลทดสอบ}
\begin{itemize}
    \item \textbf{ชุดข้อมูลทดสอบทางการแพทย์และการแบ่งชุดข้อมูล (Zero-Phrase-Leakage Split):} ใช้ชุดข้อมูลเสียงสังเคราะห์จำลองสภาวะทางคลินิกจำนวน 1,000 กรณีศึกษา ซึ่งครอบคลุมฟิลด์ข้อมูลตามมาตรฐาน CAP สำหรับโรคมะเร็งเต้านมครบทั้ง 15 ฟิลด์ จำแนกออกเป็น 10 หมวดหมู่ทางคลินิก หมวดหมู่ละ 100 กรณี โดยจัดแบ่งชุดข้อมูลแบบปราศจากการรั่วไหลของสำนวนประโยคออกเป็น 4 ชุดย่อยอย่างอิสระ ได้แก่ ชุดฝึกฝน (train, $N = 600$), ชุดตรวจสอบ (val, $N = 100$), ชุดทดสอบสำนวนใหม่ในผู้พูดกลุ่มเดิม (test\_seen, $N = 150$) และชุดทดสอบผู้พูดสำเนียงใหม่และคำศัพท์ใหม่ (test\_unseen, $N = 150$)
\end{itemize}

\subsection{ด้านฮาร์ดแวร์และเทคนิคการประมวลผล}
\begin{itemize}
    \item \textbf{สถาปัตยกรรมแบบจำลอง และกลไกการประมวลผลของระบบบูรณาการ:} ประมวลผลผ่านแบบจำลองฐาน \texttt{openai/whisper-small} ที่ได้รับการปรับแต่งค่าน้ำหนักด้วยเทคนิค LoRA ($r = 8, \alpha = 32$) ซึ่งคิดเป็นพารามิเตอร์เพียงร้อยละ 0.2434 และประมวลผลผ่านเอนจิน CTranslate2 แบบ 8 บิต (INT8 Quantization) บนหน่วยประมวลผลกลาง (CPU) ขนาด 8 เธรด หน่วยความจำหลัก (RAM) 16.0 GB โดยไม่ใช้ GPU ทำงานร่วมกับประตูตรวจวัดอัตราส่วนสัญญาณต่อเสียงรบกวนแบบไร้สัญญาณอ้างอิง (Blind SNR Gate) ณ เกณฑ์วิกฤต $\tau^* = 13.55\text{ dB}$ เพื่อเปิดใช้ตัวลดเสียงรบกวน \texttt{afftdn} เฉพาะเมื่อตรวจพบเสียงพัดลมตู้ดูดควันรบกวน ควบคู่กับการป้อนข้อความนำบริบทเชิงเปรียบเทียบเสียงพ้อง ($P_4$) ตลอดจนการประยุกต์ใช้ตัวสกัดข้อมูลแบบกำหนดแน่นอนรุ่นที่ 3 (\texttt{extractor\_v3}) สำหรับสกัดข้อมูลลงแบบฟอร์มมาตรฐาน CAP ครบทั้ง 15 ฟิลด์ ร่วมกับกลไกคัดกรองการพูดแก้ไขตัวเองกลางประโยคและการแจ้งเตือนความปลอดภัยทางคลินิกหลายสัญญาณ (Multi-Signal Safety Flagging)
\end{itemize}


\subsection{ด้านระบบแอปพลิเคชัน}
\begin{itemize}
    \item พัฒนาระบบแอปพลิเคชันด้วยเฟรมเวิร์ก Flask สำหรับให้บริการภายในเครื่องคอมพิวเตอร์ของผู้ใช้ (Locally Hosted Application) 
    \item เชื่อมต่อไปป์ไลน์ระบบบูรณาการ PathoWhisper ($S_3$) เข้ากับส่วนต่อประสานการอัปโหลดและบันทึกเสียงสด การสกัดข้อมูลและแจ้งเตือนความเสี่ยง และโมดูลสร้างเอกสารรายงานผล PDF มาตรฐาน 15 ส่วน
    \item จัดเก็บข้อมูลภายในเครื่องโดยใช้ฐานข้อมูล PostgreSQL เป็นฐานข้อมูลหลัก ร่วมกับ SQLite เป็นฐานข้อมูลสำรองในสภาวะออฟไลน์โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต
\end{itemize}

\subsection{ข้อจำกัดของโครงงาน}
\begin{itemize}
    \item ครอบคลุมเฉพาะการบันทึกข้อมูลการตรวจชิ้นเนื้อมะเร็งเต้านมด้วยตาเปล่าตามเกณฑ์ CAP โดยรองรับการบรรยายเป็นภาษาอังกฤษทางการแพทย์เท่านั้น
    \item ในกลุ่มฟิลด์วิกฤต 6 ฟิลด์หลัก การประเมินระยะห่างจากขอบตัดผ่าตัดมุ่งเน้นเฉพาะระยะห่างจากขอบตัดด้านลึก (\text{s11\_deep\_margin})
    \item ประเมินผลบนชุดข้อมูลเสียงสังเคราะห์ผสมสัญญาณเสียงรบกวนพัดลมตู้ดูดควัน จึงยังไม่สามารถใช้ยืนยันแทนการทดสอบทางคลินิกกับเสียงพูดของพยาธิแพทย์จริงในโรงพยาบาลได้
    \item ระบบทำหน้าที่เป็นเครื่องมือสนับสนุนการจัดเตรียมร่างข้อมูลเบื้องต้น โดยพยาธิแพทย์ยังคงต้องตรวจสอบและยืนยันความถูกต้องของข้อมูลก่อนนำไปใช้รับรองผลจริงทุกครั้ง
\end{itemize}

\section{ประโยชน์ที่คาดว่าจะได้รับ}

\begin{enumerate}[label=(\arabic*), leftmargin=*, align=left]
    \item ได้ต้นแบบระบบรู้จำเสียงพูดและสกัดข้อมูลทางการแพทย์ที่ประมวลผลแบบออฟไลน์บนเครื่องคอมพิวเตอร์ส่วนบุคคล ซึ่งช่วยสนับสนุนการจัดเตรียมร่างรายงานการตรวจชิ้นเนื้อเต้านมเบื้องต้นและลดขั้นตอนการพิมพ์ข้อมูลด้วยตนเอง
    \item ได้แนวทางเชิงวิศวกรรมและผลการประเมินประสิทธิภาพในการผสานกลไกคัดกรองเสียงรบกวนอัตโนมัติ การจัดโครงสร้างข้อความนำบริบท และการปรับแต่งแบบจำลองด้วยเทคนิค LoRA ร่วมกับการลดทอนความละเอียดเป็น 8 บิต (INT8) สำหรับการประมวลผลบน CPU
    \item ได้ต้นแบบสถาปัตยกรรมระบบแอปพลิเคชันที่ประมวลผลข้อมูลภายในเครื่องโดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต ซึ่งช่วยลดความจำเป็นในการส่งข้อมูลเสียงที่มีความอ่อนไหวออกไปยังบริการคลาวด์ภายนอก
\end{enumerate}
