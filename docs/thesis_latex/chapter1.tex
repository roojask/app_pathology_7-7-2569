\section{ความเป็นมาและความสำคัญของโครงงาน}

การตรวจชิ้นเนื้อด้วยตาเปล่า (Gross Examination) เป็นขั้นตอนแรกของการตรวจสิ่งส่งตรวจทางศัลยพยาธิวิทยา ในกรณีมะเร็งเต้านม พยาธิแพทย์หรือผู้ช่วยต้องวัดขนาดก้อนเนื้อในสามมิติ ประเมินระยะห่างของก้อนจากขอบตัด (Margin) ซึ่งในชิ้นเนื้อแบบ Lumpectomy มักประเมินทั้ง 6 ด้าน และนับจำนวนต่อมน้ำเหลืองที่พบ ข้อมูลเหล่านี้เมื่อรวมกับการตรวจทางจุลพยาธิวิทยาจะถูกรายงานตามโปรโตคอลของ College of American Pathologists (CAP) และใช้ประกอบการกำหนดระยะโรคตามระบบ pTNM \cite{cap_breast,ajcc2017}

ในทางปฏิบัติ ผู้ตรวจสวมถุงมือที่เปื้อนเลือด สารคัดหลั่ง และฟอร์มาลิน (สารละลายฟอร์มัลดีไฮด์ซึ่งจัดเป็นสารก่อมะเร็งในมนุษย์) จึงไม่สามารถใช้แป้นพิมพ์ได้สะดวก วิธีที่พบบ่อยคือจดลงกระดาษแล้วพิมพ์ซ้ำภายหลัง ซึ่งเสียเวลาสองต่อและเพิ่มโอกาสเกิดข้อผิดพลาดในการถ่ายโอนข้อมูล (Transcription Error) สำหรับขนาดและระยะห่างจากขอบตัด ซึ่งเป็นค่าที่มีผลต่อการรักษา ส่วนการใช้ระบบรู้จำเสียงช่วยเขียนเอกสารทางคลินิกก็ยังพบข้อผิดพลาดราว 7.4\% ของคำในผลดิบก่อนการตรวจทาน \cite{zhou2018errors}

ระบบแปลงเสียงเป็นข้อความที่ใช้กันทั่วไปส่วนใหญ่ประมวลผลบนคลาวด์ ซึ่งต้องส่งเสียงที่อาจมีข้อมูลผู้ป่วยออกนอกเครื่อง จึงมีความเสี่ยงต่อข้อกำหนดด้านการคุ้มครองข้อมูลส่วนบุคคล เช่น พระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) และ HIPAA \cite{pdpa2562,hipaa} ซึ่งข้อมูลสุขภาพจัดเป็นข้อมูลส่วนบุคคลที่อ่อนไหว นอกจากนี้ ห้องตรวจชิ้นเนื้อยังมีเสียงพัดลมของตู้ดูดควันไอระเหยอย่างต่อเนื่อง ผู้พูดมักพูดเร็ว พูดไม่เรียงตามแบบฟอร์ม และแก้ไขตัวเลขกลางประโยค แบบจำลอง Whisper \cite{radford2023whisper} สามารถทำงานแบบออฟไลน์และทนต่อเสียงรบกวนได้ดีในระดับหนึ่ง แต่เมื่อรันบน CPU ทั่วไปจะช้า และเคยมีรายงานว่าอาจสร้างข้อความที่ไม่มีอยู่ในเสียงจริงในราว 1.4\% ของช่วงเสียงที่ทดสอบ \cite{koenecke2024careless}

โครงงานนี้จึงพัฒนาระบบ PathoWhisper ซึ่งทำงานแบบออฟไลน์บนเครื่องคอมพิวเตอร์ส่วนบุคคล โดยรวมการกรองเสียงรบกวนตู้ดูดควัน การถอดความด้วย Faster-Whisper ที่ทำ INT8 Quantization ร่วมกับคลังศัพท์ CAP และตัวสกัดข้อมูลแบบกำหนดแน่นอนที่ไม่สร้างค่าขึ้นเองนอกเหนือจากที่ปรากฏในข้อความถอดความ เพื่อกรอกแบบฟอร์มและสร้างรายงาน PDF ระบบนี้ออกแบบเป็นเครื่องมือช่วยบันทึก ไม่ได้ทดแทนการตัดสินใจหรือการตรวจทานของแพทย์

\section{วัตถุประสงค์ของโครงงาน}

\begin{enumerate}
    \item เพื่อพัฒนาระบบแปลงเสียงบรรยายผลการตรวจชิ้นเนื้อทางพยาธิวิทยาขั้นต้นเป็นข้อความ โดยทำงานแบบออฟไลน์บนเครื่องคอมพิวเตอร์ส่วนบุคคล
    \item เพื่อพัฒนาการกรองเสียงรบกวนจากตู้ดูดควันร่วมกับการปรับแต่งกระบวนการถอดความ (PathoWhisper INT8) ให้เหมาะกับคำศัพท์พยาธิวิทยา
    \item เพื่อพัฒนาตัวสกัดข้อมูลทางคลินิกที่แปลงข้อความถอดความเป็นฟิลด์การบรรยายด้วยตาเปล่าที่อิงโปรโตคอล CAP สำหรับมะเร็งเต้านมและสร้างรายงาน PDF โดยอัตโนมัติ
    \item เพื่อประเมินระบบเทียบกับแบบจำลองพื้นฐานด้านอัตราความผิดพลาดระดับคำ (WER) เวลาประมวลผล และความแม่นยำของการบันทึกข้อมูลลงฟิลด์
\end{enumerate}

\section{ขอบเขตของโครงงาน}

\subsection{ด้านข้อมูล}
\begin{itemize}
    \item ชุดข้อมูลทดสอบ 1,000 กรณีศึกษา แบ่งเป็น 10 หมวดหมู่ หมวดละ 100 กรณี
    \item ไฟล์เสียง 1,000 ไฟล์ (.mp3) 1 ไฟล์ต่อ 1 กรณี ความยาวเฉลี่ย 21.48 วินาที (วัดด้วย ffprobe) ครอบคลุมเสียงปกติ การพูดเร็วเกิน 200 คำต่อนาที การพูดแก้ไขกลางประโยค และเสียงปนเสียงตู้ดูดควันที่ $-10$ dB SNR (เฉพาะหมวดที่ 8 จำนวน 100 กรณี)
    \item แหล่งที่มาของเสียง: เสียงพูดสังเคราะห์ภาษาอังกฤษด้วย Microsoft Edge TTS สองเสียง (en-US-ChristopherNeural และ en-US-JennyNeural) จากสคริปต์ที่เขียนตามถ้อยคำของโปรโตคอล CAP แล้วซ้อนทับด้วยเสียงพัดลมตู้ดูดควันที่บันทึกจากตู้จริงในหมวดที่ 8 เป็นชุดข้อมูลจำลองสภาวะแวดล้อมจริง ไม่ใช่เสียงบันทึกจากพยาธิแพทย์
    \item ไม่ใช้ข้อมูลผู้ป่วยจริง เลขที่สิ่งส่งตรวจ ขนาด และตำแหน่งเป็นค่าสมมุติตามรูปแบบของโปรโตคอล CAP จึงไม่มีผู้เข้าร่วมวิจัยและไม่ได้ขอรับรองจริยธรรมการวิจัยในมนุษย์
\end{itemize}

\subsection{ด้านเทคนิค}
\begin{itemize}
    \item การถอดความ: Faster-Whisper รุ่น Small บน CTranslate2 แบบ INT8 โดยไม่ได้ฝึกซ้ำ (Fine-tune) น้ำหนักของแบบจำลอง ปรับพฤติกรรมด้วยการตั้งค่าและการป้อนคำศัพท์ (Prompt) เท่านั้น
    \item การกรองเสียง: FFmpeg ตัวกรอง afftdn และการตัดช่วงเงียบ
    \item การสกัดข้อมูล: นิพจน์ปรกติ (Regular Expression) และกฎบริบทตามโปรโตคอล CAP สำหรับมะเร็งเต้านม จำนวน 15 ฟิลด์
    \item ฮาร์ดแวร์: CPU เสมือน (QEMU Virtual CPU) 8 โปรเซสเซอร์เชิงตรรกะ หน่วยความจำ 16 GB ไม่ใช้ GPU
\end{itemize}

\subsection{ด้านระบบ}
\begin{itemize} 
\item เว็บแอปพลิเคชันที่ให้บริการและประมวลผลภายในเครื่องผู้ใช้ (Local Web Application) และบรรจุด้วย PyInstaller เป็นแอปพลิเคชันสำหรับเครื่องเดสก์ท็อปที่เปิดใช้งานได้โดยไม่ต้องใช้บรรทัดคำสั่ง 
\item รองรับการบันทึกเสียงจากไมโครโฟนได้โดยตรงผ่านเบราว์เซอร์ 
\item อินพุต: สัญญาณเสียงจากไมโครโฟนหรือไฟล์เสียงบันทึก 
\item เอาต์พุต: ข้อความถอดความ ฟิลด์ข้อมูลที่สกัดได้ 15 ฟิลด์ และรายงานสรุปผลในรูปแบบ PDF 
\item การจัดเก็บข้อมูล: ใช้ฐานข้อมูลหลัก PostgreSQL ร่วมกับฐานข้อมูลสำรอง SQLite เพื่อรองรับการทำงานแบบออฟไลน์ 
\end{itemize}

\subsection{ข้อจำกัดของโครงงาน}
\begin{itemize}
    \item จำกัดเฉพาะการตรวจชิ้นเนื้อมะเร็งเต้านมด้วยตาเปล่า (Mastectomy และ Lumpectomy)
    \item รองรับภาษาอังกฤษทางการแพทย์เป็นหลัก ไม่ครอบคลุมการพูดสลับภาษาไทย--อังกฤษ
    \item ผลการทดสอบมาจากชุดข้อมูลเสียงสังเคราะห์ที่ใช้เพียง 2 เสียง (สำเนียงอเมริกัน) จึงไม่ครอบคลุมความหลากหลายของผู้พูดและสำเนียงจริง ยังไม่ผ่านการตรวจสอบทางคลินิกในห้องปฏิบัติการจริง และยังไม่ใช่เครื่องมือแพทย์ที่ได้รับการรับรอง
    \item ขนาดและระยะห่างจากขอบตัดที่วัดด้วยตาเปล่าเป็นค่าประมาณ การกำหนดระยะโรค pT และสถานะขอบตัดขั้นสุดท้ายต้องยืนยันด้วยการตรวจทางจุลพยาธิวิทยาเสมอ
    \item ระบบเป็นเครื่องมือช่วยบันทึกเอกสาร ไม่ใช่เครื่องมือแพทย์สำหรับการวินิจฉัย (Software as a Medical Device) ผู้ใช้ต้องตรวจทานก่อนยืนยันผลเสมอ
\end{itemize}
