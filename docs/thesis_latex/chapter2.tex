\section{งานวิจัยด้านการรู้จำเสียงในงานทางการแพทย์}

\subsection{แบบจำลอง Whisper} 
Radford และคณะ \cite{radford2023whisper} นำเสนอแบบจำลอง Whisper ซึ่งพัฒนาขึ้นบนสถาปัตยกรรม Transformer แบบ Encoder--Decoder ที่ผ่านการฝึกฝนด้วยชุดข้อมูลเสียงบนอินเทอร์เน็ตจำนวนกว่า 680,000 ชั่วโมงในลักษณะการกำกับดูแลแบบอ่อน (Weakly Supervised Learning) แบบจำลองรองรับการประมวลผลหลายภาษาและหลายงานย่อยพร้อมกัน ให้ความแม่นยำและความทนทานต่อเสียงรบกวนสูงในลักษณะ Zero-shot อย่างไรก็ตาม แบบจำลองต้นฉบับไม่ได้ปรับแต่งให้เข้ากับคำศัพท์เฉพาะทางศัลยพยาธิวิทยาและสัญญาณรบกวนความถี่ต่ำของตู้ดูดควัน

\subsection{ข้อผิดพลาดของการรู้จำเสียงในเอกสารทางคลินิก}
Zhou และคณะ \cite{zhou2018errors} ศึกษาอัตราความผิดพลาดของเอกสารทางคลินิกที่บันทึกผ่านระบบรู้จำเสียงพูดในโรงพยาบาล พบอัตราข้อผิดพลาดในผลดิบร้อยละ 7.4 ซึ่งลดลงเหลือร้อยละ 0.4 หลังผ่านการตรวจแก้โดยเจ้าหน้าที่ถอดความ และเหลือร้อยละ 0.3 ในฉบับที่แพทย์ลงนาม โดยข้อผิดพลาดส่วนใหญ่เกี่ยวข้องกับข้อมูลตัวเลข ปริมาณ และคำศัพท์เฉพาะทาง งานวิจัยดังกล่าวชี้ให้เห็นว่าระบบรู้จำเสียงทางการแพทย์จำเป็นต้องมีกระบวนการแสดงผลเพื่อให้ผู้เชี่ยวชาญตรวจทานและแก้ไขก่อนการบันทึกจริงเสมอ

\subsection{การสร้างข้อความที่ไม่มีอยู่ในเสียง (Hallucination)}
Koenecke และคณะ \cite{koenecke2024careless} ตรวจสอบความปลอดภัยของแบบจำลอง Whisper ในการประยุกต์ใช้ทางการแพทย์ พบการสร้างข้อความเกินจริง (Hallucination) ในสัญญาณเสียงราวร้อยละ 1.4 ของช่วงเสียง โดยร้อยละ 38 ของกรณีที่เกิดขึ้นมีเนื้อหาที่อาจก่อให้เกิดอันตราย เช่น การแต่งเติมชื่อยาหรือภาวะสุขภาพที่ผู้พูดไม่ได้กล่าว โดยเฉพาะอย่างยิ่งในช่วงเสียงที่มีความเงียบเป็นเวลานาน ข้อค้นพบนี้เน้นย้ำถึงความจำเป็นในการกำจัดช่วงเงียบออกจากสัญญาณเสียงก่อนการถอดความ และการใช้ระบบสกัดข้อมูลแบบกำหนดแน่นอนที่ไม่แต่งเติมข้อมูลเอง

\section{เทคนิคและเครื่องมือที่เกี่ยวข้อง}

\subsection{เทคนิคการประมวลผลสัญญาณเสียงและแบบจำลอง}
\begin{itemize}
    \item \textbf{Quantization แบบ INT8:} การแปลงค่าน้ำหนักของแบบจำลองจากเลขทศนิยม 32 บิต (FP32) เป็นจำนวนเต็ม 8 บิต (INT8) ช่วยลดขนาดการใช้หน่วยความจำลงได้ประมาณ 4 เท่า และเร่งความเร็วในการคำนวณบนสถาปัตยกรรม CPU โดยยังคงระดับความแม่นยำใกล้เคียงเดิม \cite{jacob2018quantization}
    \item \textbf{Spectral Denoising (afftdn):} ตัวกรองการลดสัญญาณรบกวนในโดเมนความถี่ของ FFmpeg โดยประมาณค่าความหนาแน่นสเปกตรัมของเสียงรบกวนและลดทอนสัญญาณแปลกปลอมอย่างมีประสิทธิภาพ \cite{ffmpeg_afftdn}
    \item \textbf{การตัดช่วงเงียบ (Silence Removal):} การตัดทอนสัญญาณเสียงส่วนที่มีระดับพลังงานต่ำกว่าเกณฑ์ที่กำหนด เพื่อลดภาระการคำนวณและป้องกันปัญหาการสร้างข้อความเกินจริงของตัวถอดความ
    \item \textbf{Prompt Conditioning:} การป้อนข้อความนำเพื่อกำหนดทิศทางการสะกดคำศัพท์เฉพาะทางและคำย่อทางการแพทย์ตามเกณฑ์ CAP ให้แก่แบบจำลอง Whisper \cite{radford2023whisper}
    \item \textbf{การสกัดข้อมูลแบบกำหนดแน่นอน (Deterministic Extraction):} การใช้ Regular Expressions และตรรกะเชิงบริบทในการจับคู่ข้อความลงฟิลด์ข้อมูล เพื่อให้ผลลัพธ์สามารถตรวจสอบย้อนกลับได้และปราศจากการสุ่มเดา
\end{itemize}

\subsection{เครื่องมือและซอฟต์แวร์}
\begin{itemize}
    \item \textbf{CTranslate2 และ Faster-Whisper:} เอนจินอนุมานประสิทธิภาพสูงสำหรับแบบจำลอง Transformer ที่เขียนด้วยภาษา C++ รองรับการคำนวณ INT8 บน CPU ซึ่งช่วยเพิ่มความเร็วในการประมวลผลขึ้นสูงสุด 4 เท่าเมื่อเทียบกับไลบรารีมาตรฐาน \cite{ctranslate2,fasterwhisper}
    \item \textbf{Vosk และ wav2vec 2.0:} สถาปัตยกรรมการแปลงเสียงเป็นข้อความแบบออฟไลน์ที่นำมาใช้เป็นแบบจำลองเปรียบเทียบประสิทธิภาพ \cite{vosk,baevski2020wav2vec}
    \item \textbf{โปรโตคอล CAP (College of American Pathologists):} เกณฑ์มาตรฐานสากลในการกำหนดโครงสร้างและฟิลด์ข้อมูลสำคัญสำหรับการรายงานผลการตรวจชิ้นเนื้อมะเร็งเต้านม \cite{cap_breast,ajcc2017} 
\end{itemize}
