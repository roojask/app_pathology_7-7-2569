\section{งานวิจัยด้านการรู้จำเสียงในงานทางการแพทย์และพยาธิวิทยา}

\subsection{การรู้จำเสียงในงานศัลยพยาธิวิทยา (Speech Recognition in Surgical Pathology)}
Hodgson และคณะ \cite{hodgson2005speech} ศึกษาการประยุกต์ใช้ระบบรู้จำเสียงพูดในห้องตรวจชิ้นเนื้อทางศัลยพยาธิวิทยา (Gross Pathology Dictation) พบว่าความท้าทายหลักของพยาธิแพทย์เกิดจากการที่มือเปื้อนเลือดและสารเคมี ทำให้ไม่สามารถสัมผัสแป้นพิมพ์ได้ อย่างไรก็ตาม ระบบรู้จำเสียงแบบดั้งเดิมมักประสบปัญหาเสียงรบกวนจากอุปกรณ์ระบายอากาศและตู้ดูดควัน (Fume Hoods) รวมถึงข้อผิดพลาดในการสะกดคำศัพท์เฉพาะทางและหน่วยวัดขนาดชิ้นเนื้อ ซึ่งส่งผลให้แพทย์ต้องใช้เวลาในการตรวจแก้รายงานค่อนข้างสูง งานวิจัยนี้ชี้ให้เห็นว่าระบบรู้จำเสียงสำหรับห้องพยาธิวิทยาจำเป็นต้องมีความทนทานต่อเสียงรบกวนของตู้ดูดควันและมีกระบวนการตรวจสอบความถูกต้องของข้อมูลเชิงโครงสร้างอย่างเป็นระบบ

\subsection{แบบจำลอง Whisper และสถาปัตยกรรมตัวแปลงสัญญาณ} 
Radford และคณะ \cite{radford2023whisper} นำเสนอแบบจำลอง Whisper ซึ่งพัฒนาขึ้นบนสถาปัตยกรรม Transformer แบบ Encoder--Decoder ที่ผ่านการฝึกฝนด้วยชุดข้อมูลเสียงบนอินเทอร์เน็ตจำนวนกว่า 680,000 ชั่วโมงในลักษณะการกำกับดูแลแบบอ่อน (Weakly Supervised Learning) แบบจำลองรองรับการประมวลผลหลายภาษาและหลายงานย่อยพร้อมกัน ให้ความแม่นยำและความทนทานต่อเสียงรบกวนสูงในลักษณะ Zero-shot อย่างไรก็ตาม แบบจำลองต้นฉบับไม่ได้ปรับแต่งให้เข้ากับคำศัพท์เฉพาะทางศัลยพยาธิวิทยาและสัญญาณรบกวนความถี่ต่ำของตู้ดูดควัน

\subsection{ข้อผิดพลาดของการรู้จำเสียงในเอกสารทางคลินิก}
Zhou และคณะ \cite{zhou2018errors} ศึกษาอัตราความผิดพลาดของเอกสารทางคลินิกที่บันทึกผ่านระบบรู้จำเสียงพูดในโรงพยาบาล พบอัตราข้อผิดพลาดในผลดิบร้อยละ 7.4 ซึ่งลดลงเหลือร้อยละ 0.4 หลังผ่านการตรวจแก้โดยเจ้าหน้าที่ถอดความ และเหลือร้อยละ 0.3 ในฉบับที่แพทย์ลงนาม โดยข้อผิดพลาดส่วนใหญ่เกี่ยวข้องกับข้อมูลตัวเลข ปริมาณ และคำศัพท์เฉพาะทาง งานวิจัยดังกล่าวชี้ให้เห็นว่าระบบรู้จำเสียงทางการแพทย์จำเป็นต้องมีกระบวนการแสดงผลเพื่อให้ผู้เชี่ยวชาญตรวจทานและแก้ไขก่อนการบันทึกจริงเสมอ

\subsection{การสร้างข้อความที่ไม่มีอยู่ในเสียง (Hallucination) และการพยากรณ์แบบคัดเลือก}
Koenecke และคณะ \cite{koenecke2024careless} ตรวจสอบความปลอดภัยของแบบจำลอง Whisper ในการประยุกต์ใช้ทางการแพทย์ พบการสร้างข้อความเกินจริง (Hallucination) ในสัญญาณเสียงราวร้อยละ 1.4 ของช่วงเสียง โดยร้อยละ 38 ของกรณีที่เกิดขึ้นมีเนื้อหาที่อาจก่อให้เกิดอันตราย เช่น การแต่งเติมชื่อยาหรือภาวะสุขภาพที่ผู้พูดไม่ได้กล่าว โดยเฉพาะอย่างยิ่งในช่วงเสียงที่มีความเงียบเป็นเวลานาน เพื่อควบคุมความเสี่ยงดังกล่าว แนวคิดการพยากรณ์แบบคัดเลือก (Selective Prediction / Classification) ของ Geifman และ El-Yaniv \cite{geifman2017selective} จึงถูกนำมาประยุกต์ใช้ในการประเมินความไม่แน่นอนของแบบจำลอง เพื่อปฏิเสธการอนุมัติรายงานอัตโนมัติและส่งต่อให้แพทย์ผู้เชี่ยวชาญตรวจทานซ้ำเมื่อความเชื่อมั่นต่ำกว่าเกณฑ์ ทั้งนี้ Guo และคณะ \cite{guo2017calibration} ได้ชี้ให้เห็นว่าโครงข่ายประสาทเทียมยุคใหม่มักมีปัญหาความมั่นใจสูงเกินจริง (Overconfidence / Probability Miscalibration) โดยเฉพาะอย่างยิ่งหลังการปรับจูนเฉพาะโดเมน ซึ่งจำเป็นต้องมีการวิเคราะห์ความน่าเชื่อถือของคะแนนความน่าจะเป็นอย่างรอบคอบ

\section{เทคนิคและเครื่องมือที่เกี่ยวข้อง}

\subsection{เทคนิคการประมวลผลสัญญาณเสียงและการปรับแต่งแบบจำลอง}
\begin{itemize}
    \item \textbf{การปรับแต่งแบบจำลองด้วยพารามิเตอร์จำนวนน้อย (Low-Rank Adaptation: LoRA):} Hu และคณะ \cite{hu2021lora} เสนอเทคนิค LoRA โดยการตรึงค่าน้ำหนักหลักของแบบจำลองขนาดใหญ่และแทรกเมทริกซ์อันดับต่ำ ($r=8, \alpha=32$) ลงในชั้นความสนใจ (Attention Projections: \texttt{q\_proj}, \texttt{v\_proj}) ของตัวถอดรหัส ช่วยให้แบบจำลอง Whisper Small สามารถปรับตัวเข้ากับสำนวนประโยคและคำศัพท์ทางการแพทย์ได้โดยปรับปรุงพารามิเตอร์เพียงร้อยละ 0.24 ของพารามิเตอร์ทั้งหมด
    \item \textbf{Quantization แบบ INT8:} การแปลงค่าน้ำหนักของแบบจำลองที่ผสานน้ำหนัก LoRA แล้วจากเลขทศนิยม 32 บิต (FP32) เป็นจำนวนเต็ม 8 บิต (INT8) บน CTranslate2 ช่วยลดขนาดการใช้หน่วยความจำลงได้ประมาณ 3 เท่า และเร่งความเร็วในการคำนวณบนสถาปัตยกรรม CPU โดยยังคงระดับความแม่นยำเทียบเท่า FP32 ทุกประการ \cite{jacob2018quantization}
    \item \textbf{การกรองสัญญาณรบกวนแบบปรับตัวและการลบสเปกตรัม (Adaptive Denoising \& Spectral Subtraction):} เทคนิคการลบสเปกตรัมดั้งเดิมที่เสนอโดย Boll \cite{boll1979suppression} มักก่อให้เกิดสิ่งแปลกปนทางเสียงดนตรี (Musical Noise Artifacts) และตัดทอนเสียงพยัญชนะเสียดแทรกหากใช้การกดสัญญาณรบกวนที่รุนแรงเกินไป ระบบ \texttt{D8\_snr\_gated} จึงประเมินค่าอัตราส่วนสัญญาณต่อเสียงรบกวนแบบไม่ต้องพึ่งสัญญาณอ้างอิง ($\widehat{\text{SNR}} = P_{85} - P_{15}$) โดยใช้เกณฑ์ขีดแบ่งที่คำนวณจากดัชนี Youden's $J$ \cite{youden1950index} เพื่อทำหน้าที่เป็นกลไกป้องกันความเสียหาย (Do-No-Harm Gate) สั่งบายพาสสัญญาณเสียงสะอาด และเปิดใช้ตัวกรองแบบอ่อนโยน \texttt{afftdn} ($\text{nr}=6\text{ dB}$) เฉพาะเมื่อตรวจพบเสียงรบกวนรุนแรง \cite{ffmpeg_afftdn}
    \item \textbf{การตัดช่วงเงียบและการถอดความตามความยาวเสียง (Silence Removal \& Duration-Aware Decoding):} การตัดทอนสัญญาณเสียงส่วนที่มีระดับพลังงานต่ำกว่าเกณฑ์ที่กำหนด และการปิดการส่งต่อบริบทข้ามหน้าต่างเวลาเมื่อความยาวเสียงเกิน 27.5 วินาที เพื่อป้องกันปัญหาการสร้างข้อความซ้ำหรือการตัดประโยคท้ายไฟล์ของตัวถอดความ \cite{koenecke2024careless}
    \item \textbf{การออกแบบข้อความนำแบบแยกส่วนเชิงตั้งฉาก (Phonetic-Contrastive Prompt Conditioning: $P_4$):} การป้อนข้อความนำที่ผสานคำศัพท์เฉพาะทางพยาธิวิทยา หน่วยวัดมาตรฐาน และคู่คำพ้องเสียงที่มักสับสน เพื่อชี้นำการแจกแจงความน่าจะเป็นของตัวถอดรหัส \cite{radford2023whisper}
    \item \textbf{การสกัดข้อมูลเชิงโครงสร้างและการทดสอบสมมติฐานทางสถิติ:} การใช้ตัวสกัดข้อมูลแบบกำหนดแน่นอนสำหรับสกัดข้อมูล 15 ฟิลด์ตามมาตรฐาน CAP ร่วมกับหลักการประมวลผลภาษาธรรมชาติเชิงอุตสาหกรรม \cite{honnibal2020spacy} และการทดสอบนัยสำคัญทางสถิติแบบจับคู่ด้วย Wilcoxon Signed-Rank Test \cite{wilcoxon1945individual}, Exact McNemar's Test \cite{mcnemar1947note}, ช่วงความเชื่อมั่น Wilson Score \cite{wilson1927probable} รวมถึงการควบคุมอัตราความผิดพลาดสะสมจากการเปรียบเทียบหลายคู่ด้วยวิธี Holm--Bonferroni \cite{holm1979simple}
\end{itemize}

\subsection{แบบจำลองเปรียบเทียบข้ามสถาปัตยกรรมและมาตรฐานทางการแพทย์}
\begin{itemize}
    \item \textbf{CTranslate2 และ Faster-Whisper:} เอนจินอนุมานประสิทธิภาพสูงสำหรับแบบจำลอง Transformer ที่เขียนด้วยภาษา C++ รองรับการคำนวณ INT8 บน CPU ซึ่งช่วยเพิ่มความเร็วในการประมวลผลขึ้นอย่างมีนัยสำคัญเมื่อเทียบกับไลบรารีมาตรฐาน \cite{ctranslate2,fasterwhisper}
    \item \textbf{Vosk, Wav2Vec 2.0, HuBERT และ WavLM:} สถาปัตยกรรมการแปลงเสียงเป็นข้อความแบบออฟไลน์ทั้งตระกูล Hybrid Kaldi FST \cite{povey2011kaldi,vosk} และตระกูล Self-Supervised Speech Representations + CTC Decoding ได้แก่ Wav2Vec 2.0 \cite{baevski2020wav2vec}, HuBERT \cite{hsu2021hubert} และ WavLM \cite{chen2022wavlm} ที่นำมาใช้เป็นแบบจำลองเปรียบเทียบประสิทธิภาพข้าม 4 ตระกูลสถาปัตยกรรม
    \item \textbf{โปรโตคอล CAP (College of American Pathologists):} เกณฑ์มาตรฐานสากลในการกำหนดโครงสร้างและฟิลด์ข้อมูลสำคัญทั้ง 15 ฟิลด์สำหรับการรายงานผลการตรวจชิ้นเนื้อมะเร็งเต้านม \cite{cap_breast,ajcc2017} 
\end{itemize}
