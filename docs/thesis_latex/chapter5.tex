\section{สรุปผล}

\begin{enumerate}
    \item \textbf{วัตถุประสงค์ข้อ 1:} พัฒนาระบบถอดความเสียงบรรยายผลการตรวจชิ้นเนื้อที่ประมวลผลบนเครื่องส่วนบุคคล ระบบถอดความ สกัดข้อมูล และสร้างรายงาน PDF ภายในเครื่องโดยไม่เรียกบริการภายนอกตามการออกแบบ (ไลบรารีของหน้าเว็บเก็บไว้ในเครื่องด้วย) แต่ยังไม่ได้บันทึกผลการทดสอบโดยตัดการเชื่อมต่ออินเทอร์เน็ตอย่างเป็นระบบ
    \item \textbf{วัตถุประสงค์ข้อ 2:} การกรองเสียงด้วย afftdn ร่วมกับ INT8, ข้อความนำ CAP และ Beam Size 1 ลด WER เฉลี่ยรายกรณีจาก 36.27\% เป็น 29.05\% (เกณฑ์เดิม) และจาก 7.25\% เป็น 2.78\% (ปรับรูปแบบมิติ) ในหมวดเสียงตู้ดูดควันลดจาก 44.88\% เป็น 31.94\% โดยการทดลองวิเคราะห์องค์ประกอบแบบสะสม (Progressive Component Analysis) ในหมวด 8 ยืนยันว่าการใช้ INT8 ร่วมกับ Beam Size 1 ช่วยลด WER เหลือ 20.52% และลดเวลาประมวลผลเหลือ 9.62 วินาที
    \item \textbf{วัตถุประสงค์ข้อ 3:} ตัวสกัดข้อมูลแบบกำหนดแน่นอนกรอกฟิลด์และสร้างรายงาน PDF ได้ F1 เฉลี่ยของ 11 ฟิลด์ที่มีการกล่าวถึงเปลี่ยนจาก 96.26\% เป็น 96.97\% ขนาดก้อน 3 มิติเป็นฟิลด์ที่ได้ผลต่ำที่สุด (Recall 80.4\%) และตัวปรับข้อความผ่านการทดสอบหน่วย 16 จาก 16 กรณีหลังแก้กฎ
    \item \textbf{วัตถุประสงค์ข้อ 4:} เวลาประมวลผลเฉลี่ยลดจาก 20.04 เป็น 11.50 วินาทีต่อกรณี (เร็วขึ้น 1.74 เท่า RTF จาก 0.933 เป็น 0.535) การลด WER และเวลามีนัยสำคัญทางสถิติเมื่อจับคู่ระดับกรณี
\end{enumerate}

ผลทั้งหมดได้จากชุดข้อมูลเสียงสังเคราะห์ 1,000 กรณี ซึ่งมีเพียงหมวดเสียงตู้ดูดควัน 100 กรณีที่ซ้อนเสียงพัดลมที่บันทึกจริง ยังไม่ผ่านการทดสอบทางคลินิกในห้องปฏิบัติการจริง และระบบเป็นเครื่องมือช่วยบันทึกที่ผู้ใช้ต้องตรวจทานก่อนยืนยันผล ค่าที่วัดด้วยตาเปล่าเป็นค่าประมาณ ระยะโรค pT ต้องยืนยันด้วยการตรวจทางจุลพยาธิวิทยาเสมอ

\section{ข้อจำกัดที่สำคัญ}

\begin{itemize}
    \item \textbf{ข้อบกพร่องของตัวสกัด:} ขนาดสิ่งส่งตรวจและขนาดก้อนผิดเมื่อประโยคเรียงต่างจากลำดับปกติหรือมีการแก้ค่า (ตารางที่ \ref{tab:caterr}) และกฎแก้ไขกลางประโยครุ่นแรกเคยลบมิติโดยไม่แจ้งผู้ใช้ ซึ่งแก้แล้วแต่ทดสอบกับกรณีที่ทราบแล้วเท่านั้น
    \item \textbf{ฟิลด์ที่ประเมินไม่ได้เต็มรูปแบบ:} 4 ฟิลด์ (หัวนม แผลเป็น โพรงเดิม ก้อนหลงเหลือ) ไม่ถูกกล่าวถึงในชุดทดสอบ จึงวัดได้เฉพาะการไม่คืนค่าเกิน ไม่ได้วัดความสามารถในการสกัดเมื่อมีการพูดถึง และขอบตัดประเมินเฉพาะด้านลึก
    \item \textbf{Ablation:} การทดลองตัดทอนองค์ประกอบดำเนินการในหมวดที่มีความท้าทายทางเสียงสูง (หมวด 8 ตู้ดูดควัน N = 5 กรณี) ยังไม่ได้ครอบคลุมครบทุกหมวด
    \item \textbf{ข้อมูลทดสอบ:} เสียงสังเคราะห์ 2 เสียง สำเนียงอเมริกัน เฉลยสร้างจากตัวแปรของสคริปต์สร้างข้อมูล ไม่ได้ผ่านการตรวจรายกรณีโดยพยาธิแพทย์ และกฎบางข้อพัฒนาโดยดูผลบนชุดเดียวกัน
    \item \textbf{การทำงานแบบออฟไลน์:} ได้รับการตรวจสอบทรัพยากรส่วนหน้า (Frontend Assets) แบบ Local ครบถ้วน (T9 ผ่าน 100%) แต่ยังไม่ได้บันทึกการทดสอบในสภาวะตัดสัญญาณเครือข่ายทางกายภาพในห้องปฏิบัติการจริง
\end{itemize}

\section{ข้อเสนอแนะ}

\begin{itemize}
    \item \textbf{แก้กฎการจับคู่ลำดับและการวิเคราะห์คำปฏิเสธ (Clinical NLP):} (1) แก้ปัญหาในหมวดที่ 2 โดยให้ตัวสกัดระบุมิติจากคำขยายทางความหมาย (Semantic Head เช่น specimen, mass) แทนการยึดลำดับที่ปรากฏ (2) แก้ปัญหาข้อผิดพลาดบวกเกิน (False Positive) ในหมวดที่ 6 โดยปรับใช้ขั้นตอนวิธีตรวจจับคำปฏิเสธทางการแพทย์ (เช่น NegEx หรือ Lightweight Clinical Transformer) เพื่อป้องกันไม่ให้คำปฏิเสธหลุดขอบเขตจนกลายเป็นก้อนมะเร็งลุกลาม
    \item \textbf{ชุดทดสอบฟิลด์ที่ยังไม่ถูกกล่าวถึง:} เพิ่มกรณีที่พูดถึงหัวนม แผลเป็น โพรงเดิม ก้อนหลงเหลือ และขอบตัดทุกด้าน เพื่อวัด Recall ของฟิลด์เหล่านี้
    \item \textbf{ชุดทดสอบที่แยกอิสระ (Held-out Prospective Validation):} ทดสอบกับชุดข้อมูลภายนอกที่ไม่ได้ใช้พัฒนากฎของตัวปรับข้อความและตัวสกัด เพื่อป้องกันภาวะ Overfitting ต่อข้อมูลสังเคราะห์
    \item \textbf{Ablation ที่ทำซ้ำได้:} รันแยกองค์ประกอบโดยตั้ง temperature เป็น 0 และ seed คงที่ เก็บผลรายกรณี เพื่อทราบผลของ afftdn, Prompt, INT8 และ Beam Size
    \item \textbf{การตรวจสอบกับการใช้งานจริง:} ทดสอบกับเสียงมนุษย์จริง โดยเฉพาะผู้พูดชาวไทยที่พูดอังกฤษทางการแพทย์ ในห้องที่มีเสียงตู้ดูดควันจริง ภายใต้การรับรองด้านจริยธรรม และให้พยาธิแพทย์ตรวจถ้อยคำเฉลย
    \item \textbf{การช่วยตรวจทานและความปลอดภัยของข้อมูล (Human-in-the-Loop \& Safety Watermark):} แสดงข้อความถอดความดิบควบคู่ฟิลด์ ไฮไลต์ฟิลด์ที่ถูกแก้ไขกลางประโยคหรือมีความเชื่อมั่นต่ำ แจ้งเตือนเมื่อระบบลบข้อมูลเดิม และใส่ลายน้ำกำกับชัดเจนบนเอกสาร PDF/DOCX ว่า ``เอกสารฉบับร่างขั้นต้น ต้องผ่านการตรวจยืนยันโดยพยาธิแพทย์'' (Preliminary Draft) จนกว่าจะมีการลงนามอิเล็กทรอนิกส์
    \item \textbf{การเปรียบเทียบอย่างเป็นธรรม:} แปลงคำอ่านตัวเลขของ Vosk และ wav2vec 2.0 กลับเป็นตัวเลขก่อนคำนวณ WER
    \item \textbf{การ Fine-tune:} ทดลอง Fine-tune หรือ LoRA กับเสียงจริงที่ได้รับอนุญาต แล้วเปรียบเทียบกับแนวทาง Prompt
    \item \textbf{การเชื่อมต่อระบบสารสนเทศโรงพยาบาล (HIS/LIS) และความปลอดภัย:} กำหนดสิทธิ์การเข้าถึงตามบทบาท (Role-Based Access Control: ผู้ช่วยผ่าตรวจ vs พยาธิแพทย์ผู้ตรวจรับรอง), บันทึกประวัติการแก้ไขที่ไม่สามารถแก้ไขย้อนหลังได้ (Immutable Audit Trail) ตามมาตรฐาน HIPAA และ PDPA, รองรับแป้นเหยียบ USB สั่งบันทึกเสียง และเชื่อมต่อ LIS ผ่านมาตรฐาน HL7 หรือ FHIR
    \item \textbf{การนำไปใช้จริง:} เปลี่ยนเซิร์ฟเวอร์ที่ใช้พัฒนาเป็นเซิร์ฟเวอร์ระดับใช้งานจริง และทบทวนข้อกำหนดของเครื่องมือแพทย์ (SaMD) ก่อนใช้กับผู้ป่วย
\end{itemize}

\section{บทส่งท้าย}

โครงงานนี้แสดงให้เห็นว่าระบบแปลงเสียงเป็นข้อความแบบออฟไลน์ที่ปรับให้เหมาะกับเสียงรบกวนและศัพท์เฉพาะของห้องตรวจชิ้นเนื้อ สามารถลดความผิดพลาดของการถอดความและเวลารอเมื่อเทียบกับ Whisper Small ได้ในชุดทดสอบสังเคราะห์ แต่การสกัดข้อมูลลงฟิลด์ยังต้องปรับปรุงและตรวจสอบกับการใช้งานจริงก่อน หากแก้ข้อบกพร่องที่พบและผ่านการทดสอบกับเสียงจริง ระบบอาจช่วยลดการจดซ้ำและการสัมผัสแป้นพิมพ์ขณะปฏิบัติงาน โดยยังคงให้ผู้เชี่ยวชาญเป็นผู้ตัดสินใจขั้นสุดท้าย
