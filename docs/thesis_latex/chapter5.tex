\section{สรุปผลการดำเนินงาน}

\begin{enumerate}
    \item \textbf{การพัฒนาระบบถอดความแบบออฟไลน์:} พัฒนาระบบ PathoWhisper ในรูปแบบเว็บแอปพลิเคชันที่สามารถทำงานแบบออฟไลน์อย่างสมบูรณ์บนคอมพิวเตอร์ส่วนบุคคล โดยผ่านการทดสอบการทำงานครบถ้วนทุกโมดูล และผ่านการตรวจสอบการประมวลผลในสภาวะตัดการเชื่อมต่อเครือข่ายภายนอก (Offline Execution Verification)
    \item \textbf{การบูรณาการกระบวนการประมวลผลเสียงและแบบจำลอง:} ระบบผสานตัวกรองสัญญาณรบกวน afftdn การตัดช่วงเงียบ และ Faster-Whisper INT8 ร่วมกับคลังศัพท์ CAP สามารถลดค่า WER เกณฑ์ B จากร้อยละ 7.25 เหลือร้อยละ 2.78 และในสภาวะเสียงรบกวนตู้ดูดควัน ($-10$ dB SNR) ลดจากร้อยละ 44.88 เหลือร้อยละ 31.94
    \item \textbf{การพัฒนาตัวสกัดข้อมูลและการสร้างรายงาน:} ตัวสกัดข้อมูลแบบกำหนดแน่นอนสามารถแปลงข้อมูลลงแบบฟอร์ม CAP 15 ฟิลด์ และส่งออกเอกสารรายงาน PDF ได้อย่างมีประสิทธิภาพ โดยลดอัตราความผิดพลาดระดับเคส ($\mathrm{CER}_{\mathrm{case}}$) จากร้อยละ 18.80 เหลือร้อยละ 11.10 และให้ค่า $\mathrm{Macro\text{-}}F_1$ เฉลี่ยรวมที่ร้อยละ 98.61
    \item \textbf{ประสิทธิภาพการประมวลผลเชิงเวลา:} ระบบสามารถลดเวลาประมวลผลเฉลี่ยจาก 20.04 วินาที เหลือ 11.50 วินาทีต่อกรณี คิดเป็นอัตราเร่งความเร็ว 1.74 เท่าบนสถาปัตยกรรม CPU
\end{enumerate}

\section{ข้อจำกัดที่สำคัญ}
\label{sec:limits}

การประเมินผลและการประยุกต์ใช้งานระบบยังมีข้อจำกัดที่ต้องพิจารณาอย่างรอบคอบ ดังนี้:

\begin{itemize}
    \item \textbf{ลักษณะของชุดข้อมูลทดสอบ:} ชุดข้อมูลเสียงสังเคราะห์ขึ้นจากระบบ TTS โดยใช้เพียง 2 รูปแบบเสียงจำลอง จึงยังขาดความหลากหลายของสำเนียง ระดับเสียง และพฤติกรรมการพูดที่เป็นธรรมชาติของแพทย์ผู้ตรวจจริง
    \item \textbf{การปรับปรุงตัวสกัดข้อมูลแบบวนซ้ำ (Iterative Refinement):} กฎการสกัดข้อมูลและตัวปรับข้อความได้รับการปรับปรุงโดยอิงจากข้อผิดพลาดที่พบบนชุดทดสอบหลัก ค่าความถูกต้องที่รายงานจึงถือเป็นขอบเขตบนเชิงประสิทธิภาพ (Performance Upper Bound) ซึ่งต้องได้รับการตรวจสอบความเที่ยงตรงด้วยชุดข้อมูลภายนอกอิสระ
    \item \textbf{การเปรียบเทียบทั้งระบบและการแยกองค์ประกอบ:} baseline และ PathoWhisper ต่างกันหลายองค์ประกอบพร้อมกัน (ไลบรารี INT8 Beam Size ข้อความนำ และตัวกรองเสียง) และการแยกองค์ประกอบทำได้เพียง 5 กรณี จึงระบุไม่ได้ว่าองค์ประกอบใดทำให้ WER ลดลง เกณฑ์ WER B กำหนดหลังพิจารณาผลของเกณฑ์ A และฟิลด์หัวนม แผลเป็น โพรงเดิม และก้อนตกค้างไม่มีค่าบวกในชุดทดสอบ จึงไม่ได้ทดสอบความสามารถในการตรวจจับ
    \item \textbf{ความเปราะบางของตรรกะแบบตรงตัว (Exact-Match Vulnerability):} การสกัดข้อมูลขึ้นอยู่กับความสมบูรณ์ของคำสำคัญ หากแบบจำลองถอดเสียงคำพยางค์เดียวผิดพลาด (เช่น คำว่า deep หรือ discrete) อาจส่งผลให้ระบบเว้นว่างข้อมูลหรือรายงานผลบวกลวงในกรณีชิ้นเนื้อที่ไม่ใช่มะเร็ง
    \item \textbf{ขอบเขตของธงแจ้งเตือนทางคลินิก:} ระบบธงแจ้งเตือนความเชื่อมั่นในปัจจุบันครอบคลุมข้อผิดพลาดของเคสวิกฤตได้เพียงร้อยละ 30.60 ซึ่งยังมีกรณีผิดพลาดที่ไม่มีการแจ้งเตือนอีกร้อยละ 69.40
    \item \textbf{สถานะการใช้งานเชิงระบบ:} ระบบจัดเป็นซอฟต์แวร์ต้นแบบสำหรับงานวิจัย ยังไม่ผ่านการรับรองมาตรฐานเครื่องมือแพทย์ และจำเป็นต้องใช้ใบรับรองความปลอดภัยระดับองค์กรก่อนการติดตั้งในโรงพยาบาล
\end{itemize}

\section{ข้อเสนอแนะสำหรับการวิจัยและพัฒนา}

\subsection{ด้านการประมวลผลภาษาและการประเมินผล}
\begin{itemize}
    \item \textbf{การทดสอบด้วยชุดข้อมูลทางคลินิกจริง:} ดำเนินการยื่นขอรับรองจริยธรรมการวิจัยในมนุษย์เพื่อบันทึกและประเมินประสิทธิภาพระบบด้วยเสียงของพยาธิแพทย์ไทยในสภาวะการทำงานจริง
    \item \textbf{การพัฒนาโมดูลสกัดข้อมูลด้วย Clinical NLP:} ผสานเทคโนโลยีการประมวลผลภาษาธรรมชาติเชิงคลินิกแบบเปิด (เช่น Rule-based BioNLP หรือ Small Specialized Language Models) เพื่อรองรับความยืดหยุ่นของโครงสร้างประโยคและลดความเปราะบางต่อการสะกดคำผิด
    \item \textbf{การปรับปรุงระบบธงเตือนความเชื่อมั่นระดับฟิลด์:} พัฒนาตัวชี้วัดความเชื่อมั่นของการถอดเสียงรายคำ (Token-level Confidence) เพื่อระบุตำแหน่งฟิลด์ที่น่าสงสัยได้อย่างแม่นยำ
\end{itemize}

\subsection{ด้านสถาปัตยกรรมระบบและการนำไปใช้งานจริง}
\begin{itemize}
    \item \textbf{การเชื่อมโยงระบบสารสนเทศห้องปฏิบัติการ (LIS):} พัฒนาส่วนต่อประสานตามมาตรฐานสากล เช่น HL7 หรือ FHIR เพื่อให้สามารถรับส่งข้อมูลกับระบบเวชระเบียนได้อย่างไร้รอยต่อ
    \item \textbf{ระบบรักษาความปลอดภัยและการควบคุมสิทธิ์ (RBAC):} กำหนดระดับสิทธิ์การเข้าถึงข้อมูลระหว่างเจ้าหน้าที่เตรียมสิ่งส่งตรวจและพยาธิแพทย์ผู้รับรองผล พร้อมทั้งสร้างระบบเก็บบันทึกประวัติการแก้ไขข้อมูล (Audit Trail) ตามเกณฑ์มาตรฐาน PDPA
    \item \textbf{การเชื่อมต่ออุปกรณ์ควบคุมภายนอก:} พัฒนาระบบรองรับสวิตช์แป้นเหยียบ (USB Foot Pedal) เพื่อให้ผู้ตรวจสามารถควบคุมการบันทึกเสียงแบบ Hands-free อย่างสมบูรณ์
\end{itemize}

\section{บทส่งท้าย}

โครงงาน PathoWhisper ได้พิสูจน์ความเป็นไปได้เชิงเทคนิคในการนำปัญญาประดิษฐ์รู้จำเสียงพูดมาประมวลผลแบบออฟไลน์เพื่อสนับสนุนงานศัลยพยาธิวิทยา แม้ระบบจะแสดงศักยภาพในการลดภาระงานพิมพ์ แต่การรักษามาตรฐานความปลอดภัยของผู้ป่วยยังคงเป็นหัวใจสำคัญสูงสุด ระบบนี้จึงถูกออกแบบมาเพื่อเสริมศักยภาพและสนับสนุนการทำงาน โดยแพทย์ผู้ตรวจยังคงเป็นศูนย์กลางในการตรวจสอบและตัดสินใจขั้นสุดท้ายทางคลินิกเสมอ
