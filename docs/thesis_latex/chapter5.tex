\section{สรุปผลการดำเนินงานตามวัตถุประสงค์}

\begin{enumerate}
    \item \textbf{การออกแบบระเบียบวิธีวิจัยไร้อคติและชุดข้อมูลครบ 15 ฟิลด์ CAP:} พัฒนาชุดข้อมูล 1,000 กรณีศึกษาที่ครอบคลุมทั้ง 15 ฟิลด์มาตรฐาน CAP ครบทุกฟิลด์ (มีเคสบวกในทุกฟิลด์รวมถึง \texttt{s6\_nipple}, \texttt{s7\_biopsy\_scar}, \texttt{s8\_cavity} และ \texttt{s9\_residual\_mass}) โดยแยกสำนวนประโยคระหว่างชุดฝึกฝน (\texttt{train} 600 กรณี), ชุดตรวจสอบ (\texttt{val} 100 กรณี) และชุดทดสอบ (\texttt{test\_seen} 150 กรณี, \texttt{test\_unseen} 150 กรณี) อย่างเคร่งครัดร้อยละ 0.00 (Zero-Phrase-Leakage) โดยตัวสกัดข้อมูล \texttt{extractor\_v3} ที่พัฒนาจากชุดฝึกฝนเพียงอย่างเดียวสามารถทำค่า $\mathrm{Macro\text{-}}F_1$ บนข้อความอ้างอิงเฉลยได้ร้อยละ 100.00 ($\mathrm{CER}_{\mathrm{case}} = 0.00\%$)
    \item \textbf{กลไกกรองสัญญาณรบกวนแบบปรับตัวด้วยเกณฑ์อัตโนมัติ (Blind SNR-Gated Adaptive Denoising):} ออกแบบตัวประมาณค่า $\widehat{\mathrm{SNR}} = P_{85} - P_{15}$ จากพลังงานเฟรมสั้น 25 มิลลิวินาที และปรับเทียบค่าขีดแบ่งที่เหมาะสมที่สุดบนชุดตรวจสอบได้ $\tau^* = 13.55\text{ dB}$ ($J = 1.0000$) ร่วมกับการค้นหาพารามิเตอร์ตัวกรอง \texttt{afftdn} ที่เหมาะสมที่สุดคือ $\mathrm{nr} = 6\text{ dB}$ ผลการทดสอบบนชุดข้อมูลทดสอบ 300 กรณีพบว่าสวิตช์อัตโนมัติคัดแยกสัญญาณได้แม่นยำร้อยละ 98.67 (296/300 กรณี) รักษาความแม่นยำในทุกช่วงความรุนแรงของเสียงรบกวน ($\mathrm{SNR}$ ตั้งแต่ Clean ถึง $-10\text{ dB}$) และลดอัตราความผิดพลาดวิกฤตระดับเคส ($\mathrm{CER}_{\mathrm{case}}$) เทียบกับการเปิด \texttt{afftdn} คงที่แบบเดิมจากร้อยละ 18.00 (54/300) เหลือร้อยละ 13.00 (39/300) อย่างมีนัยสำคัญทางสถิติ ($p = 0.0015$)
    \item \textbf{การแยกองค์ประกอบของข้อความนำบริบทและการปรับแต่งน้ำหนักเชิงลึกด้วย LoRA:} การศึกษาเปรียบเทียบข้อความนำบริบท ($P_0 \dots P_4$) พิสูจน์ให้เห็นว่าคลังคำศัพท์ ($P_2$) ลดเฉพาะความผิดพลาดของคำศัพท์แพทย์ (C-TER: $10.11\% \rightarrow 3.64\%$) ส่วนรูปแบบตัวเลข ($P_3$) ลดเฉพาะความผิดพลาดของมิติตัวเลข (N-DER: $3.20\% \rightarrow 0.27\%$) และเมื่อผสานเป็นพรอมต์เปรียบเทียบเสียงพ้อง ($P_4$) สามารถลดความผิดพลาดทั้งสองมิติพร้อมกัน การปรับแต่งน้ำหนักแบบจำลอง Whisper Small ด้วย LoRA ($r=8, \alpha=32$ บน 48 โมดูลในชั้นถอดรหัส คิดเป็นพารามิเตอร์ร้อยละ 0.2434) บนชุดฝึกฝน 600 กรณี จำนวน 3 Epoch ทำให้ $\mathrm{val\_loss}$ ลดลงเหลือ 0.2189 และเมื่อควบรวมเป็นโมเดล CTranslate2 INT8 ในระบบ PathoWhisper ฉบับสมบูรณ์ ($S_3$) สามารถลด $\mathrm{CER}_{\mathrm{case}}$ จากแบบจำลองพื้นฐาน ($S_0$) บน \texttt{test\_seen} จากร้อยละ 12.67 (19/150) เหลือเพียงร้อยละ 5.33 (8/150, $p = 0.0127$, $\mathrm{Macro\text{-}}F_1 = 99.13\%$) และบน \texttt{test\_unseen} ลดลงกว่าครึ่งหนึ่งจากร้อยละ 24.00 (36/150) เหลือร้อยละ 11.33 (17/150, $p = 6.60 \times 10^{-5}$)
    \item \textbf{กลไกแจ้งเตือนความปลอดภัยหลายสัญญาณและการบูรณาการเข้ากับเว็บแอปพลิเคชัน:} ระบบคัดกรองความปลอดภัยที่ผสานค่าความมั่นใจทางเสียง ($\mathrm{avg\_logprob}, \mathrm{min\_word\_prob}$) คำเตือนคำพ้องเสียง และการตรวจสอบความสอดคล้องข้ามฟิลด์ สามารถดักจับเคสที่มีข้อผิดพลาดวิกฤตได้ครบถ้วนร้อยละ 100.00 ในระบบ Zero-Shot ($S_0, S_{1a}, S_{1c}$) บน \texttt{test\_seen} และร้อยละ 88.46--97.22 บน \texttt{test\_unseen} โดยแลกกับภาระการตรวจทานซ้ำร้อยละ 43.33--68.00 ในขณะที่แบบจำลองที่ผ่านการปรับจูน LoRA 600 เคส ($S_2, S_3$) ลดภาระการตรวจทานเหลือเพียงร้อยละ 27.33--33.33 โดยรักษาอัตราความผิดพลาดวิกฤตแบบเงียบ (Silent CER) ไว้ต่ำที่ร้อยละ 1.83--1.96 บน \texttt{test\_seen} และ 5.00--7.77 บน \texttt{test\_unseen} ทว่าเผชิญกับปรากฏการณ์ความมั่นใจเกินพิกัด (Calibration Drift) ที่ทำให้ Error Recall ลดลงเหลือร้อยละ 52.94--75.00 ซึ่งสามารถแก้ไขได้ด้วยการสอบเทียบเกณฑ์ใหม่บนชุดตรวจสอบ และไปป์ไลน์ทั้งหมดได้รับการเชื่อมต่อเข้ากับเว็บแอปพลิเคชัน Flask (\texttt{app.py}) พร้อมผ่านการทดสอบการทำงานแบบ End-to-End ครบทุกโมดูลภายใต้เวลาประมวลผลเฉลี่ย 5.75--6.57 วินาทีต่อกรณี ($\mathrm{RTF} \approx 0.23\text{--}0.25$) บน CPU
\end{enumerate}

\section{ข้อจำกัดที่สำคัญของงานวิจัย}
\label{sec:limits}

แม้การออกแบบการทดลองใหม่จะช่วยแก้ไขข้อจำกัดด้านการรั่วไหลของสำนวนประโยค การกรองเสียงแบบคงที่ การขาดการปรับแต่งน้ำหนักเชิงลึก และความเสี่ยงของข้อผิดพลาดเงียบได้ครบถ้วน แต่งานวิจัยนี้ยังมีข้อจำกัดที่ต้องระบุอย่างโปร่งใส ดังนี้:

\begin{itemize}
    \item \textbf{การใช้ชุดข้อมูลเสียงสังเคราะห์หลายผู้พูดผสมเสียงรบกวนจริง (Multi-Speaker Synthetic Speech with Real Fume-Hood Noise):} แม้ชุดทดสอบ \texttt{test\_unseen} จะแยกผู้พูดและคำศัพท์คลินิกออกจากชุดฝึกฝนอย่างเคร่งครัด แต่สัญญาณเสียงพูดหลักยังคงสร้างจากเอนจินสังเคราะห์เสียงประสาทเทียม จึงยังไม่ได้ครอบคลุมความแปรผันทางสัทศาสตร์ของเสียงมนุษย์จริงทั้งหมด เช่น สำเนียงภาษาอังกฤษของพยาธิแพทย์ไทย (Thai-Accented Medical English) เสียงพูดที่อู้อี้จากการสวมหน้ากากอนามัย N95 หรือเสียงสะท้อนภายในห้องผ่าตัดขนาดใหญ่
    \item \textbf{การแลกเปลี่ยนระหว่างภาระการตรวจทานกับการเลื่อนของการสอบเทียบ (Review Workload Trade-off \& Calibration Drift):} ในระบบตั้งต้นแบบ Zero-Shot เพื่อให้ได้ความครอบคลุมในการดักจับข้อผิดพลาดวิกฤตร้อยละ 92.59--100.0 เกณฑ์การแจ้งเตือนแบบอนุรักษนิยมจะส่งสัญญาณให้แพทย์ตรวจสอบซ้ำประมาณร้อยละ 43--68 ของกรณีศึกษาทั้งหมด ในขณะที่เมื่อนำ LoRA เข้ามาช่วยลดอัตราความผิดพลาดระดับเคสลงเหลือร้อยละ 5.33--11.33 และลดอัตราการยกธงเตือนเหลือเพียงร้อยละ 27--33 แบบจำลองกลับมีความมั่นใจสูงขึ้นในโทเคนที่ทำนายผิดพลาด ส่งผลให้อัตราการดักจับข้อผิดพลาดลดลงเหลือร้อยละ 52.94--75.00 ดังนั้น การนำไปใช้ทางคลินิกจึงต้องใช้การปรับจูนขีดแบ่งแบบเฉพาะเจาะจงกับโมเดล LoRA (Domain-Adapted Thresholding) หรือใช้การจัดอันดับความเสี่ยงแบบต่อเนื่องเพื่อควบคุมความเสี่ยงตามทรัพยากรการตรวจทานของแพทย์
    \item \textbf{สถานะการรับรองมาตรฐานเครื่องมือแพทย์:} ระบบ PathoWhisper มีสถานะเป็นระบบสนับสนุนการบันทึกข้อมูลเบื้องต้นเพื่อการวิจัย (Research Assistive Prototype) ยังไม่ได้ผ่านการทดลองทางคลินิกในผู้ป่วยจริง (Prospective Clinical Trial) และยังไม่ได้ขึ้นทะเบียนเป็นซอฟต์แวร์เครื่องมือแพทย์ (SaMD)
\end{itemize}

\section{ข้อเสนอแนะสำหรับการวิจัยและพัฒนาในอนาคต}

\begin{itemize}
    \item \textbf{การกำหนดมาตรฐานอุปกรณ์รับเสียงในห้องปฏิบัติการ (Acoustic Hardware Guidelines):} เพื่อให้สัญญาณเสียงมีอัตราส่วนสัญญาณต่อสัญญาณรบกวนอยู่ในช่วงที่แบบจำลองทำงานได้อย่างมีประสิทธิภาพสูงสุด ($\mathrm{SNR} > +10\text{ dB}$) และลดความจำเป็นในการเปิดใช้ตัวกรองตัดเสียงรบกวน ควรแนะนำให้ติดตั้งไมโครโฟนก้านคอยาวปรับทิศทางได้ (Directional Gooseneck) หรือไมโครโฟนคาดศีรษะ (Headset Mic) ที่มีรูปแบบการรับเสียงแบบ Cardioid / Supercardioid ร่วมกับแผ่นกรองฟองน้ำกันลม (Windscreen) ติดตั้งใกล้ปากผู้พูดในระยะไม่เกิน 5--10 เซนติเมตร เพื่อป้องกันเสียงลมหายใจและตัดเสียงรบกวนตู้ดูดควันตั้งแต่ต้นทางทางกายภาพ
    \item \textbf{การศึกษาวิจัยทางคลินิกในสภาพแวดล้อมจริง (IRB-Approved Clinical Pilot Study):} นำระบบการเก็บข้อมูลแบบหมุนเวียน (Clinical Audio Data Flywheel) ที่พัฒนาไว้ในเว็บแอปพลิเคชันไปบันทึกเสียงบรรยายจริงของพยาธิแพทย์และแพทย์ประจำบ้านสาขาพยาธิวิทยา ภายใต้การรับรองของคณะกรรมการจริยธรรมการวิจัยในมนุษย์ เพื่อปรับแต่ง LoRA เพิ่มเติมด้วยเสียงพูดสำเนียงไทยจริง
    \item \textbf{การปรับแต่งแบบจำลองร่วมกับโทเคนเวลาสำหรับเสียงบรรยายขนาดยาว (Timestamp-Aware LoRA Adaptation):} แทรกโทเคนเวลา ($\texttt{<|0.00|>}\dots\texttt{<|30.00|>}$) ลงในชุดข้อมูลฝึกฝน LoRA โดยตรง เพื่อให้แบบจำลองสามารถเลื่อนหน้าต่างเวลาในไฟล์เสียงที่ยาวเกิน 30 วินาทีได้โดยไม่ต้องสลับโหมดการถอดรหัส
    \item \textbf{การเชื่อมโยงระบบสารสนเทศห้องปฏิบัติการและแป้นเหยียบควบคุม (LIS Integration \& Hands-Free Foot Pedal):} ขยายโมดูลส่งออกข้อมูล FHIR ที่พัฒนาไว้ในระบบให้เชื่อมต่อโดยตรงกับระบบสารสนเทศโรงพยาบาล (HIS/LIS) และเชื่อมต่อกับแป้นเหยียบ USB (Foot Pedal) เพื่อให้แพทย์ควบคุมการเริ่มและหยุดบันทึกเสียงได้โดยไม่ต้องสัมผัสอุปกรณ์ใด ๆ
\end{itemize}

\section{บทส่งท้าย}

โครงงาน PathoWhisper ได้พิสูจน์ให้เห็นว่าการบูรณาการการประมวลผลสัญญาณเสียงแบบปรับตัวตามระดับเสียงรบกวน การออกแบบข้อความนำบริบทเชิงสัทศาสตร์ การปรับแต่งแบบจำลองเชิงลึกด้วย LoRA ควบคู่กับการลดทอนความละเอียดเป็น INT8 และกลไกคัดกรองความปลอดภัยหลายสัญญาณ สามารถยกระดับความแม่นยำและความปลอดภัยของระบบแปลงเสียงเป็นข้อความแบบออฟไลน์บนคอมพิวเตอร์ส่วนบุคคลได้อย่างมีนัยสำคัญทางสถิติ โดยระบบทำหน้าที่เป็นผู้ช่วยลดภาระงานเอกสารและป้องกันความผิดพลาดในการถ่ายโอนข้อมูล ขณะที่พยาธิแพทย์ยังคงเป็นผู้ตรวจสอบและตัดสินใจขั้นสุดท้ายเพื่อประโยชน์และความปลอดภัยสูงสุดของผู้ป่วยเสมอ
